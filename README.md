## Análise de Dados Financeiros – CVM

Este projeto tem como objetivo realizar a análise de dados financeiros de empresas brasileiras utilizando dados públicos disponibilizados pela Comissão de Valores Mobiliários (CVM).

### Objetivo
Transformar dados financeiros brutos em informações relevantes por meio de processos de coleta, tratamento, análise exploratória e visualização, apoiando a tomada de decisão baseada em dados.

### Fonte dos Dados
Os dados utilizados são públicos e foram obtidos diretamente do portal de dados abertos da CVM:
https://dados.cvm.gov.br/dados/CIA_ABERTA/DOC/DFP/

### Tecnologias Utilizadas
- Python
- Pandas
- SQL
- Power BI
- Excel

### Etapas do Projeto
1. Coleta e compreensão dos dados financeiros
2. Tratamento e padronização das informações
3. Análise exploratória e criação de indicadores
4. Visualização dos resultados em dashboards

### Resultados Esperados
- Indicadores financeiros consolidados
- Dados organizados para análise
- Insights para apoio à tomada de decisão
